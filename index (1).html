Автоматизация

Задача

AI-ассистент по документам

AI / ML

Задача

Нужен был помощник, который быстро находит ответы в документах и при этом не отправляет данные во внешние сервисы.

Решение

Развернул локальную модель через LM Studio, настроил AnythingLLM, загрузил PDF-базу знаний и прописал системный промпт с жёстким ограничением: отвечать только по содержимому документов.

Результат

Ассистент корректно отвечает на вопросы по базе и отказывается отвечать, когда информации в документах нет.

Клиентская запись из Telegram в календарь

Автоматизация

Задача

Нужно было сделать запись на дату и время через Telegram, чтобы после бронирования слот становился недоступным.

Решение

Клиент видит свободные даты и время, нажимает кнопку "Записаться" в Telegram. После этого в календаре статус выбранного слота меняется на "Забронировано".

Результат

Запись происходит прямо в Telegram, а календарь автоматически обновляется и не даёт забронировать уже занятое время.

Технологии
Make/n8n Telegram Google Calendar API
